ไฟล์ HD-Records จะถูกเขียนในนามบัญชี Google ของหมอ (Service account เขียนลง My Drive ไม่ได้ — Google ไม่ให้โควตา) · ขอสิทธิ์เฉพาะไฟล์ที่ระบบสร้างเอง (drive.file) ไม่เห็นไฟล์อื่นใน Drive · ไฟล์จะอยู่ในโฟลเดอร์ RANONG-RAKTAI-HD-Records ที่ระดับบนสุดของ My Drive (ระบบสร้างให้เอง)

📱 LINE Alert Recipients (แพทย์)
ใส่ LINE userId จริงของแพทย์ (เริ่มต้นด้วย U) — เมื่อมี critical/warning alert ระบบจะ push LINE ไปหาทันที
คำสั่งแพทย์, สรุปเวร, Pre-HD reminder, อุบัติการณ์ จะถูกส่งเข้ากลุ่มนี้ผ่าน LINE OA (Messaging API) — LINE Notify ปิดบริการแล้ว ไม่ต้องใช้ token อีก
วิธีตั้งค่ากลุ่มพยาบาล (ทำครั้งเดียว):
  1. ในกลุ่ม LINE ของทีมพยาบาล → เชิญบัญชี OA ของคลินิกเข้ากลุ่ม
  2. พิมพ์ groupid ในกลุ่ม → บอทตอบ Group ID (ขึ้นต้นด้วย C)
  3. คัดลอกมาวางช่องด้านบน → 💾 บันทึก → กด "ทดสอบส่งเข้ากลุ่ม"
วิธีหา LINE User ID ของตัวเอง:
  1. เปิด LINE OA ของคลินิก (RANONG-RAKTAI-AI)
  2. พิมพ์ myid ในแชท
  3. ระบบจะตอบกลับ LINE User ID ของคุณ (เช่น U1234567890abcdef)
  4. คัดลอก ID นั้นมาวางที่นี่แล้วกด 💾 บันทึก
👨‍⚕️ LINE ID แพทย์ (สำหรับส่งสรุปรอบฟอก)
เมื่อพยาบาลกด "ส่ง LINE หมอ" หลังฟอกเสร็จ ระบบจะส่งสรุปไปที่ ID นี้
